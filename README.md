# Clothes Thief (Fabric, Minecraft 26.3)

## איך משחקים
- **להתפשט:** הפקודה `/undress` – הבגדים שלך הופכים לפריט (Clothes) ואתה עירום.
- **לקחת בגדים:** כשאתה עירום (ואין לך בגדים בסלוט) – Shift + קליק ימני עם יד ריקה על שחקן או כפרי. הם נשארים עירומים (כפרים – לתמיד) ואתה לובש את הבגדים שלהם (כולל הראש/הסקין).
- **סלוט בגדים:** בממשק המלאי, מעל סלוט היד השנייה (קואורדינטות ב-`InventoryMenuMixin`).
- **ללבוש פריט:** קליק ימני על פריט Clothes (רק כשאתה עירום) או גרירה לסלוט.
- אם שניכם עירומים – לא קורה כלום. אחרי מוות חוזרים לבגדים הטבעיים.
- אפשר לזרוק, לסחור ולשים בתיבות – זה פריט רגיל.

## בנייה
דורש Java 25. `./gradlew build` ← הקובץ ב-`build/libs/clothesthief-1.0.0.jar` (לא ה-sources).
או: העלאה ל-GitHub, והקובץ יוצא מ-Actions → Artifacts.
